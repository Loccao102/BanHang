# Sơ đồ LSOUL dùng trong báo cáo Word

41 sơ đồ được bố trí thành 104 phần để đọc trên giấy A4. Chữ Times New Roman 13 pt, màu đen, nền trắng. Mỗi phần không quá 440 × 560 pt; trong Word được đặt đúng kích thước này, giữ cỡ chữ thực tế 13 pt.

- Sơ đồ tuần tự giữ số bước liên tục, lặp các đối tượng tham gia và điều kiện khi sang phần mới.
- Sơ đồ hoạt động nối các phần bằng ký hiệu A/B/C.
- Use case được chia theo nhóm liên quan; các use case cần thiết được lặp để đọc từng phần độc lập.
- ERD chia theo quan hệ khóa ngoại, có lặp bảng; các bảng và thuộc tính vẫn được giữ đủ.

## Mở và chỉnh sửa

- **draw.io:** File → Open from → Device, chọn `LSOUL-So-do-de-doc.drawio`.
- **Visual Paradigm Online:** Import / Open → Import draw.io, chọn `LSOUL-So-do-de-doc.xml`.
- Chọn từng tệp trong `drawio/` hoặc `visual-paradigm-online/` để sửa riêng một phần.
- `anh-svg/` là ảnh vector, `anh-png/` là ảnh 216 dpi, `pdf/` chứa từng phần dưới dạng vector.
