# Sơ đồ LSOUL nguyên hình

41 sơ đồ hoàn chỉnh, mỗi sơ đồ là một hình, không chia phần. Dùng Times New Roman 13 pt, chữ và nét đen, nền trắng. Sơ đồ rộng được bố trí cho một trang A4 nằm ngang. 24 sơ đồ tuần tự dùng lifeline nét đứt, thanh kích hoạt, mũi tên gọi và phản hồi riêng; ảnh PNG xuất ở 288 dpi, kèm SVG/PDF vector và tệp có thể chỉnh sửa.

- Mở `LSOUL-So-do-nguyen-hinh.drawio` trong draw.io.
- Trong Visual Paradigm Online, chọn Import draw.io và mở `LSOUL-So-do-nguyen-hinh.xml`.
- Có thể mở từng tệp riêng trong `drawio/` hoặc `visual-paradigm-online/`.
- `anh-svg/` và `pdf/` là ảnh vector; `anh-png/` là ảnh 288 dpi.
